## Appendix A — facade-gap report for go-fabric (filed as go-fabric #584)

**Title:** A sealer a host can build through the facade (`store.NewAESGCMSealer` is below it)

- **Why.** go-fabric-server (a host that imports go-fabric through its facades only, guarded by its `internal/arch`) wants to
  seal the controller's database once `controller.Config.KeepOnboardingCodes` puts one setup code per node into it
  (go-fabric-server #70). `controller.Config.Sealer` (`controller/controller.go:159-182`) and `node.Store.Sealer`

  (`script/archcheck/layers.json:6`), not of the facade (`:11`). A facade-only host can name the option but not fill it

  must tell apart at start (`store.ErrUnseal`, `store.ErrNoSealer`) reachable for `errors.Is` from the controller facade;
  `controller.Reseal` (`controller/reseal.go:39`) already is.
