## Differences from the brief

- `Credential.Default` added (§1): the brief said nothing to add; U8's
  "Hosts" text asks for it.
- An erase does not call `publish()`: the entry (the switch as `Source`,
  the `Erase` func) is unchanged, and the call would take the registry's
  lock inside the half's, against `Delete`'s order (registry, then half).
- `erase_failed` is a page warning too (`8422688`, owner's session,
  2026-11-08), not only a log line.
- §3's bit-1 QR row is not a generated code: no facade encoder sets
  capabilities (go-fabric v0.18.0 `node/credentials.go:102`,
  `controller/client/window.go:149`; `secure/setup` is below the facade).
  The row sets `capabilityBLE` on a decoded documented example.
- No version, `addon/config.yaml`, `addon/CHANGELOG.md` or release commit
  (owner's instruction); the report is commit 5, not part of a release
  commit.
