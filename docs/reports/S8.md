## Differences from the brief

- No release commit (owner's instruction). `README.md`'s status line
  already names v0.7.0.
- `Services.Camera` may be nil: three more `Start` callers than the brief
  lists (`internal/daemon/controllerui_test.go`, `multinode_test.go`,
  `bridgeapi/harness_test.go`) pass the topology only; such a backend
  leaves the eight commands out of `capabilities` and answers them
  `InvalidCommand` naming the missing service (`gapOf`). The gap message
  lost "in go-fabric".
- The test camera is opt-in (`envOptions.camera`): fabrictest carries TCP
  on loopback sites only.
- 104 is tested with the port refusing `VideoStreamDeallocate` with
  `contract.StatusError{Status: 0xCB}`; an initial `ReferenceCount` is not
  the kit's count.
- 104 and 106 carry matterjs-server's message texts; go-fabric's
  `Error()` prefixes `camera:` (104) and appends the modes (106).
- Queued candidates: one `Session.ProvideICECandidates` answers every
  queued command with one outcome — a deliberate difference in
  `docs/protocol.md`. Their order is the arrival order since the review
  (below).
- `ice_candidates` by key are decoded by the server (types and keys only):
  `controller/camera` exports no JSON converter.
- `send_webrtc_provider_command`'s response is rendered from the generated
  struct by the schema's property names: no facade turns an `Encodable`
  into a `client.Value`.
- A closing connection's `Release` runs synchronously in `close`, bounded
  to 10 s (`//nolint:contextcheck` at the two `close` callers).

## Decisions

- An owned session's `camera_session_ended` goes out after its last
  `webrtc_callback`: the end is handed to the drain when it arrives first.
- A held end is matched to an unanswered start by owner, node, endpoint
  and key; at the response only the end of the answered session is kept.
- Arguments are checked before the node is looked up; `node_id` first.
- `ice_transport_policy` and `client_session_key` refuse `""` with "must
  be a non-empty string": the ceilings are go-fabric's, so the server does
  not word them.
